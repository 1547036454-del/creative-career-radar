# 深圳创意岗位雷达

面向深圳资深设计从业者的公开岗位快照和求职工具。

保留筛选、来源详情、收藏、投递跟进、薪资计算、手动补录、CSV导出、JSON备份/导入，以及 BOSS 直聘与智联招聘的原站验证入口。

个人收藏和投递记录只保存在当前浏览器。更换网址时，请在旧站点击“导出 / 备份”导出 JSON，在新站点击“导入更新”导入备份。不同浏览器和手机之间也需要通过备份迁移。

岗位为采集时的快照，请通过岗位原站核实是否仍在招聘。登录原站不会自动刷新本站快照。

## 2026-10-13 功能优化

新增公开字段岗位分级及依据、专业/管理信号筛选、七类作品准备清单、本机核对记录与失效筛选、导入前后新发现比较，以及手机底部导航。恢复旧备份时保留较新的岗位快照。

功能版本更新不等于重新采集；默认岗位快照仍为2026-10-12。新发现按本机前后数据比较，未读到不代表失效。收藏、核对结果和投递跟进只保存在各自浏览器，可导出JSON备份迁移。
